# 🌦️ SkyCast – Smart Weather & Agriculture Advisory System

**SkyCast** is a web-based project designed to help users understand weather conditions and get basic agriculture-related suggestions through a simple and user-friendly interface.

It combines weather information with agriculture advisory features to support better farming decisions.

## 🚀 Features

SkyCast includes the following modules:

1. **Weather Dashboard** – Displays current weather information and forecast.
2. **Agriculture Advisory** – Provides general farming suggestions.
3. **Crop Recommendation** – Suggests suitable crops based on selected conditions.
4. **Farming Calendar** – Displays a general farming activity calendar.
5. **Farmer Profile** – Allows users to save their basic farming details.
6. **Farm Analytics Dashboard** – Displays simple farming-related analytics.
7. **SkyBot Chatbot** – Provides basic answers to agriculture-related questions.
8. **Advisory History** – Stores and displays previous advisory entries.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and interactive features
- **Open-Meteo API** – Weather information
- **Local Storage** – Saves profile and history data in the browser

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `SkyCast_Frontend_One_File.html` in Google Chrome or another modern browser.
4. Allow internet access for live weather information.
5. Explore the different modules using the navigation menu.

## 🌐 API Used

SkyCast uses the **Open-Meteo API** to retrieve weather information.

Website: https://open-meteo.com/

No API key is required for the basic weather functionality used in this project.

## 💾 Data Storage

- Farmer profile details are saved using browser Local Storage.
- Advisory history is stored in browser Local Storage.
- Weather information is fetched through the internet.

**Note:** This single-file version is a frontend demonstration. It does not use the Flask and SQLite backend.

## 🎯 Project Objective

The main objective of SkyCast is to combine weather information and basic agriculture guidance in one platform. It aims to make useful farming-related information easier to access through a simple web interface.
